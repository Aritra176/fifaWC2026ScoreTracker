# FIFA World Cup 2026 Score Tracker

A comprehensive web application designed to track real-time scores, matches, and statistics for the FIFA World Cup 2026 tournament.

## Overview

The FIFA World Cup 2026 Score Tracker is your one-stop solution for staying updated with all tournament matches, live scores, team standings, and player statistics throughout the championship.

## Features

- **Live Match Tracking**: Real-time score updates for all FIFA World Cup 2026 matches
- **Tournament Schedule**: Complete fixture list with dates and match times
- **Team Standings**: Dynamic league tables showing points, wins, losses, and goal differences
- **Match Statistics**: Detailed statistics including goals, assists, yellow/red cards, and possession
- **Player Information**: Track top scorers, assists leaders, and player performances
- **Filtering & Search**: Easily find specific matches, teams, or players
- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **User-Friendly Interface**: Intuitive navigation and clean layout for seamless browsing

## Goals

- Provide real-time, accurate, and up-to-date information on FIFA World Cup 2026 matches
- Enable fans to track their favorite teams and players throughout the tournament
- Display comprehensive statistics and match analytics
- Offer a seamless user experience across all devices
- Serve as a reliable resource for World Cup enthusiasts and sports analysts

## Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Architecture**: Single Page Application (SPA)

## Installation

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/yourusername/fifaWC2026ScoreTracker.git
   ```

2. Navigate to the project directory:
   ```bash
   cd fifaWC2026ScoreTracker
   ```

3. Open `index.html` in your web browser to launch the application.

## Usage

1. Open the application in your web browser
2. Browse through the tournament schedule and matches
3. Click on any match to view detailed statistics
4. Filter by teams or dates to find specific matches
5. Check team standings and player statistics
